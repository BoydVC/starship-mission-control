# Starship & Starlink Mission Control

Wall-display dashboard for SpaceX launch countdowns, Starlink fleet facts, and Elon/xAI theme cards. Built as a **Grok Bot weekly burn** remaster under TokenMax.

**URL:** http://127.0.0.1:4335  
**Port:** `4335` via `./run.sh`

Every number on the board is tagged **LIVE** (fetched this session from public pages) or **SYNTHETIC** (local framing / Parent A-interest notes). This is not official SpaceX telemetry and not investment advice.

---

## 2-min how-to

```bash
cd /workspace/tokenmax/starship-mission-control
./run.sh            # start (idempotent)
./run.sh status     # confirm pid + health
# open http://127.0.0.1:4335/
./run.sh test       # smoke PASS
./run.sh stop       # when done
```

Tabs on the wall:

1. **Countdown** — next Falcon window + Starship Flight 15 planning NET, live T-minus.
2. **Starlink** — in-orbit / working / launched metrics, shells, latest lift, milestones.
3. **Themes** — Grok Bot enterprise, V3 capacity, LC-39A, FAA PEIS, Raptor 3 notes.
4. **Why Parent A cares** — SYNTHETIC household/interest framing over LIVE facts.

API quick checks:

```bash
curl -s http://127.0.0.1:4335/api/health | python3 -m json.tool
curl -s http://127.0.0.1:4335/api/snapshot | python3 -c 'import sys,json;d=json.load(sys.stdin);print(d["live_fact_count"])'
```

Snapshot file: `data/snapshot.json` (rebuild by editing + restart; no external cron).
